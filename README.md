# 京东订单导出助手

一个本地运行的 Chrome 扩展，用来导出京东网页版订单，并把可获取的电子发票打包成 ZIP。

这个项目的原则很简单：只处理你浏览器里已经登录后的京东页面，不保存账号密码，不上传订单数据，不绕过验证码或风控。

## 能做什么

- 导出京东历史订单。
- 支持全部订单、最近一年、自定义时间范围。
- 支持勾选导出字段，例如订单号、下单时间、店铺、商品、金额、状态、收货信息、发票入口等。
- 支持导出 `CSV`、`Excel 兼容 CSV`、`JSON`。
- 自动过滤取消、退款、退货等非正常订单。
- 后台静默扫描，不需要一直停留在京东订单页面。
- 支持把发票 PDF 打包成一个 ZIP 下载。
- 可选把 XML 也一起放进 ZIP，默认不包含 XML。

## 安装方式

目前先用开发者模式安装：

1. 下载或克隆本项目。
2. 打开 Chrome，进入 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目文件夹。

安装后，浏览器右上角会出现“京东订单导出”扩展入口。

## 使用方式

1. 在 Chrome 里登录京东。
2. 打开扩展弹窗。
3. 选择时间范围和导出字段。
4. 点击“开始扫描”。
5. 等扫描完成，或中途点击“停止”导出已扫描结果。
6. 点击 `Excel 兼容 CSV`、`CSV` 或 `JSON` 下载订单数据。
7. 如需发票，点击“打包发票 ZIP”。

发票下载会先收集文件，再生成一个 ZIP。不会把几百个 PDF/XML 直接塞进 Chrome 下载列表。

## 权限说明

扩展会申请这些权限：

- `storage`：在本地保存扫描状态和已扫描订单。
- `downloads`：下载订单导出文件和发票 ZIP。
- `offscreen`：在后台生成 ZIP 文件。
- `activeTab`：支持扩展弹窗与当前页面配合。
- `https://*.jd.com/*`、`https://*.360buy.com/*`：读取京东订单和发票页面。
- `https://*.jdcloud-oss.com/*`：下载京东发票文件。

## 隐私说明

- 不收集账号密码。
- 不读取浏览器密码库。
- 不上传订单、Cookie、发票或个人信息到任何服务器。
- 订单和发票只在你的本机浏览器环境中处理。
- 如果遇到登录失效、验证码或安全验证，需要你自己在京东页面完成。

## 开发与测试

本项目是 Manifest V3 Chrome 扩展，主要代码使用原生 JavaScript ES Modules。

运行测试：

```bash
npm test
```


## 适用边界

京东网页结构可能变化。如果页面改版导致解析失败，需要更新解析规则。

这个工具只适合导出自己的京东订单。不要拿它做越权访问、账号共享、Cookie 转交或任何违反平台规则的事情。
